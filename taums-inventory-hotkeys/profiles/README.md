# Mod shortcut profiles

These example profiles use the mods and settings in the supplied mod list. Copy the `profiles` folder into the installed `taums-inventory-hotkeys` folder while the game is closed. Keep the installed root `config.json`; each profile belongs in `profiles/hotkeys-profile-N.json`.

| Profile | Contents |
| --- | --- |
| 1 | Chests Anywhere, Quest Helper, Chirp Valley, Horse Overhaul, Pocket Glide |
| 2 | World Navigator, Trinket Tinker, UI Info Suite 2 Alternative, The Living Valley, NPC Map Locations, Perfection Handbook, Hire Skilled Helpers |
| 3 | It's StardewTime only |
| 5 | UltraSmooth, MultiSave - Continued, UI Info Suite 2 Alternative, Automate, Sword & Sorcery |

The configured keyboard shortcuts are unique among these actions. Living Valley uses `[`, `]`, and `~` for its newspaper, rumour, and farmhand boards. The affected mod settings use keyboard-only bindings; controller alternatives were removed from those fields. Sword & Sorcery's Adventure Bar actions only work after the Adventure Bar has been unlocked. Horse Overhaul's pet-menu shortcut is intended to open its pet friendship/feeding menu. If it opens Stardew's Animals tab instead, that's not the documented behavior and needs an in-game check for a remaining mod conflict.

World Navigator's Lookup Guidance shortcut was removed because it wasn't working. Quest Helper has no configurable keybind in this installation, so its profile entry remains unbound. The hotkey entries send keys to the game; they don't change other mods' settings. Set the corresponding keys in each mod's config as shown in its profile.
